# Ajustements de vocabulaire UI

## 2026-09-14

Les comparaisons affichées dans les KPI et les familles utilisent désormais un vocabulaire compréhensible pour l'utilisateur :

- `ancienne valeur` pour la valeur affichée à gauche ;
- `valeur actuelle` pour la valeur affichée à droite ;
- `première valeur enregistrée` lorsqu'il n'existe pas encore de comparaison ;
- `dernière actualisation de la source` dans le détail d'un KPI.

Les noms techniques comme `previousFetch` restent inchangés dans les contrats et le code interne.
