# Trading Decision Platform

Plateforme personnelle d’analyse décisionnelle destinée à centraliser l’exploration des setups et des inflexions, le suivi macroéconomique, le journal analytique et les futurs pipelines de données.

## État du projet

Projet en phase initiale de conception.

## Modules prévus

- Explorateur de setups et d’inflexions
- Dashboard macroéconomique
- Journal analytique
- Pipelines d’importation et d’actualisation
- Base de données
- Outils d’analyse statistique
