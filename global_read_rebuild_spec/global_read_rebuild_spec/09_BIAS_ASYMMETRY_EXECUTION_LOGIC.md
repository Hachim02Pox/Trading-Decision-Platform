# 2. Phase II — résoudre les contradictions

Construire les scénarios qui expliquent le maximum de faits avec le minimum d’hypothèses artificielles.

Comparer :

- causal coherence ;
- timing ;
- priced/unpriced ;
- market response ;
- missing evidence ;
- alternative scenario.

Ne pas compter les facteurs.

---

# 3. Phase III — proposition de biais

Sorties possibles :

### CLEAR SUPPORTIVE GOLD THESIS
Un scénario domine clairement.

### CLEAR ADVERSE GOLD THESIS
Un scénario adverse domine clairement.

### CONDITIONAL THESIS
Direction dépend d’un trigger.

### COMPETING SCENARIOS
Pas encore de dominance.

### NO EDGE
Pas d’asymétrie exploitable.

# 5. Une thèse vraie peut rester non-exploitable

Exemples :

- déjà totalement pricée ;
- crowding extrême ;
- catalyst imminent ;
- price failure ;
- aucun marginal buyer ;
- short gamma amplifie dans mauvais sens ;
- data critique inconnue.

Le biais et le trade sont deux étapes différentes.

---

# 6. Le concept d’asymétrie

Le trader cherche une situation où :

- scénario principal suffisamment robuste ;
- scénario adverse identifié ;
- prix / positioning / flow créent un rapport favorable ;
- catalyst / trigger existe ;
- invalidation claire ;
- la perte conceptuelle si faux est maîtrisable par le setup du trader ;
- le potentiel si juste est supérieur.

Le moteur ne calcule pas automatiquement le R:R technique.

Il évalue la **qualité asymétrique du contexte**.

---

# 7. Que doit dire le moteur près d’un support/résistance ?

Pas :

BUY SUPPORT.

Mais par exemple :

> « La thèse Gold-supportive reste valide. Le marché n’a pas encore intégralement repricé X. Le positionnement n’est pas suffisamment crowded pour neutraliser l’asymétrie. Le prochain risque est Y. La thèse s’affaiblit si Z. Si ton setup technique apparaît, le contexte reste compatible. »

Ou :

> « La thèse macro reste supportive, mais le flow est extrêmement étendu et la favorable news ne génère plus de follow-through. Le contexte n’offre plus la même asymétrie. »

---

# 8. Invalidation vs flip

### INVALIDATION
La thèse actuelle cesse d’être supportée.

Cela ne signifie pas automatiquement l’opposé.

### FLIP
La thèse opposée devient elle-même suffisamment supportée.

Exemple :

Supportive invalidated
≠
automatiquement adverse.

Il peut exister un état neutral / unresolved.

---

# 9. Dernière question avant le trade

> **Si le trader me donne maintenant une zone technique, est-ce que le macro/fundamental/mechanical context lui donne une raison suffisamment forte de considérer l’expression de cette thèse ?**

Cette question produit l’output opérationnel.
