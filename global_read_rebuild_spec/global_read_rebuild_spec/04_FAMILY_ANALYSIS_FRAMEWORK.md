# 04 — CADRE D’ANALYSE DE CHAQUE FAMILLE

Chaque famille passe d’abord par une lecture indépendante, « toutes choses égales par ailleurs ».

Le but n’est PAS de conclure le trade.

Le but est de savoir précisément ce que cette famille raconte avant la synthèse.

---

# 1. Questions invariantes pour chaque famille

Pour CHAQUE famille, répondre :

### Q1 — Quelles données sont réellement disponibles et vérifiées ?
- valeurs ;
- timestamps ;
- cadence ;
- source ;
- définition ;
- éventuels conflits.

### Q2 — Est-ce un niveau ou un changement ?
Un niveau élevé peut être ancien et déjà pricé.

Un changement marginal peut être beaucoup plus important.

### Q3 — Quelle est la direction interne de la famille ?
Exemples :
- hawkish/dovish ;
- tightening/easing ;
- stress/no stress ;
- USD strengthening/weakening ;
- flow expanding/contracting.

### Q4 — Quelle est la surprise par rapport aux attentes ?
Pas seulement actual.

Actual vs expected vs prior.

### Q5 — Quel mécanisme relie cette famille à Gold ?
Écrire la chaîne.

### Q6 — Quel est l’horizon naturel de cette information ?
- intraday ;
- days ;
- weeks ;
- structural.

Ne pas mélanger.

### Q7 — Cette information est-elle déjà pricée ?
Si oui, comment le sait-on ?

### Q8 — Qu’est-ce qui pourrait faire changer cette lecture ?
Nommer les prochaines observations / catalysts.

### Q9 — Qu’est-ce qui contredit la lecture de cette famille ?
Chercher activement les contradictions internes.

### Q10 — Qu’est-ce qui manque ?
La famille doit pouvoir dire :
UNKNOWN.

---

# 2. Sortie indépendante de chaque famille

Chaque famille produit conceptuellement :

- `state` ;
- `goldImplicationCeterisParibus` ;
- `marginalChange` ;
- `alreadyPricedAssessment` ;
- `causalMechanism` ;
- `forwardCatalysts` ;
- `contradictions` ;
- `missingEvidence` ;
- `confidenceBasis` non numérique ;
- `role`.

Important :
`goldImplicationCeterisParibus` n’est pas le biais final.

---

# 3. La famille ne vote pas

La sortie famille ne produit pas :

+1 bullish
-1 bearish.

Elle produit :
une pièce structurée du puzzle.

---

# 4. Exemple conceptuel

Taux :

- 2Y en hausse ;
- 10Y en hausse davantage ;
- real yield stable ;
- breakeven monte.

Une mauvaise lecture :
« yields up → bearish Gold ».

Une meilleure lecture :
- front-end n’est pas seul driver ;
- long-end decomposition suggère inflation/term premium ;
- real yield stable ;
- le mécanisme opportunity-cost n’est donc pas entièrement confirmé ;
- vérifier USD, Treasury/fiscal, breakeven et risk.

La famille crée une question pour la synthèse.

---

# 5. Contradictions inter-familles

Une fois toutes les familles analysées indépendamment, créer une matrice de contradictions :

Exemples :

- rates adverse / USD favorable ;
- growth weak / credit calm ;
- risk-off / Gold fails to rise ;
- ETF inflow / COT reduction ;
- hawkish data / Fed pricing dovish ;
- supportive catalyst / price failure.

Chaque contradiction doit être expliquée ou rester explicitement ouverte.

---

# 6. Ce qui domine

Après les lectures indépendantes seulement, poser :

> **Quelle famille ou chaîne causale explique le changement marginal le plus important de l’information set maintenant ?**

C’est le début du `marginalDriver`.

Le driver ne vient pas automatiquement du dernier headline.
