# 06 — LES QUESTIONS FINALES À LAQUELLE CHAQUE IA DOIT RÉPONDRE

Ces questions arrivent **après** :

- vérification des données ;
- analyse individuelle des familles ;
- première interprétation ;
- exploration web ;
- réintégration des éléments nouveaux.

Elles servent à transformer la complexité en structure commune.

Elles ne sont pas un questionnaire scolaire.

Elles forcent chaque IA à exposer son raisonnement de façon comparable.

---

# QUESTION 1 — DANS QUEL RÉGIME SOMMES-NOUS ?

Répondre :

- inflation ;
- growth ;
- labour ;
- liquidity ;
- funding ;
- financial conditions ;
- risk ;
- fiscal ;
- policy.

Pourquoi ?

Parce que la même donnée n’a pas le même effet selon le régime.

---

# QUESTION 2 — QU’EST-CE QUI A CHANGÉ MARGINALEMENT ?

Pas :
« qu’est-ce qui est important dans l’absolu ? »

Mais :
**qu’est-ce qui vient de modifier la distribution ?**

Pourquoi ?

Les marchés réagissent aux changements d’information.

---

# QUESTION 3 — QUEL EST LE DRIVER MARGINAL LE PLUS CRÉDIBLE ?

Décrire :

CATALYST  
→ REPRICING  
→ TRANSMISSION  
→ GOLD

S’il n’y en a pas :
le dire.

Pourquoi ?

On ne veut pas une collection de thèmes.

On veut savoir ce qui domine maintenant.

---

# QUESTION 4 — QUELLES FAMILLES CONFIRMENT OU CONTREDISENT CE DRIVER ?

Passer explicitement :

- taux ;
- Fed/pricing ;
- USD/FX ;
- inflation ;
- employment/growth ;
- risk/credit/vol ;
- liquidity/funding ;
- Treasury/fiscal ;
- structural ;
- options/vol ;
- flows/positioning.

Pourquoi ?

La contradiction n’est pas un bug.

Elle doit être comprise.

---

# QUESTION 5 — QU’EST-CE QUI EST DÉJÀ PRICÉ ?

Répondre :

- consensus ;
- market-implied expectations ;
- positioning ;
- price response déjà effectué ;
- éventuelles surprises déjà absorbées.

Pourquoi ?

Une thèse correcte mais entièrement pricée peut offrir zéro edge.

---

# QUESTION 6 — QU’EST-CE QUI N’EST PAS ENCORE PRICÉ / QU’EST-CE QUI PEUT REPRICER ?

Chercher :

- prochaine release ;
- surprise potentielle ;
- Fed communication ;
- auction ;
- fiscal ;
- geopolitical ;
- flow ;
- positioning vulnerability ;
- options expiry ;
- funding shock ;
- autre catalyst.

Pourquoi ?

C’est la composante forward-looking.

---

# QUESTION 7 — QUEL EST LE SCÉNARIO PRINCIPAL ?

Décrire :

- hypothèse ;
- mécanisme ;
- faits ;
- conditions ;
- path attendu ;
- prochain trigger.

Le scénario principal n’est pas nécessairement bullish/bearish dès le départ.

Il peut être conditionnel.

---

# QUESTION 8 — QUEL EST LE SCÉNARIO ADVERSE LE PLUS SOLIDE ?

Pas une caricature.

Construire la meilleure lecture opposée.

Puis répondre :

- pourquoi est-elle crédible ?
- pourquoi est-elle actuellement moins crédible, si c’est le cas ?
- qu’est-ce qui la ferait devenir dominante ?

Pourquoi ?

Un bon biais doit survivre à la meilleure objection, pas à une objection faible.

---

# QUESTION 9 — OÙ SONT LES VRAIES CONTRADICTIONS NON RÉSOLUES ?

Nommer les contradictions qui restent.

Pour chacune :

- explication possible ;
- importance ;
- ce qui permettrait de trancher.

Pourquoi ?

Le système ne doit jamais masquer un trou.

---

# QUESTION 10 — QUE DISENT LE POSITIONNEMENT ET LES FLUX UNE FOIS LA THÈSE PROPOSÉE ?

Ici seulement, analyser l’exploitabilité.

### Sous-question A
Quel flux est réellement observé ?

### Sous-question B
Le marché est-il sous-positionné, normal, étendu ou extrêmement étendu ?

### Sous-question C
La participation se renforce-t-elle ou se contracte-t-elle ?

### Sous-question D
Prix et flux se confirment-ils ou divergent-ils ?

### Sous-question E
Existe-t-il un crowded condition qui réduit l’asymétrie ?

Pourquoi ?

Le positionnement ne crée pas automatiquement la thèse.

Il indique comment la thèse peut être exprimée ou piégée.

---

# QUESTION 11 — QUE DISENT OPTIONS / VOL / HEDGING UNE FOIS LA THÈSE PROPOSÉE ?

Si données fiables disponibles :

- vol regime ;
- skew ;
- OI ;
- gamma ;
- short/long gamma ;
- hedging mechanics ;
- expiries ;
- call/put concentration ;
- pinning/amplification.

Pourquoi ?

Ces mécanismes peuvent :
- amplifier ;
- ralentir ;
- pinner ;
- créer une asymétrie différente de la macro.

---

# QUESTION 12 — QUI EST L’ACHETEUR / VENDEUR MARGINAL POTENTIEL ?

Attention :
ne pas inventer des acteurs.

Répondre seulement avec des mécanismes observables ou documentés.

Questions :

- quel flux peut encore arriver ?
- qui est réellement contraint ?
- qui peut être forcé à couvrir / réduire ?
- quel participant a encore capacité/incitation à agir ?
- la thèse suppose-t-elle un nouvel acheteur qui n’existe pas ?

Pourquoi ?

Une thèse a besoin d’un mécanisme de demande/offre future.

---

# QUESTION 13 — OÙ EST LE FUNDING / CARRY / CONSTRAINT ?

Examiner si pertinent :

- funding stress ;
- USD funding ;
- carry ;
- JPY carry ;
- leverage ;
- liquidity ;
- margin ;
- forced deleveraging.

Pourquoi ?

Un participant peut avoir raison fondamentalement et perdre parce qu’il est contraint mécaniquement.

---

# QUESTION 14 — QUEL EST LE « FUSE » ?

Quel événement ou changement peut déclencher :

- continuation ;
- unwind ;
- reversal ;
- repricing rapide ?

Pourquoi ?

Une asymétrie sans trigger peut rester dormante.

---

# QUESTION 15 — LE PRIX RÉPOND-IL COMME IL DEVRAIT ?

Questions :

- bonne news → bon mouvement ?
- mauvaise news → mauvaise réaction ?
- favorable catalyst mais aucun follow-through ?
- contradiction ?
- news failure ?

Pourquoi ?

Le prix sert à tester la thèse, pas à l’inventer.

---

# QUESTION 16 — OÙ EST L’ASYMÉTRIE ?

Pas seulement probabilité de direction.

Demander :

- quel scénario semble le mieux soutenu ?
- qu’est-ce qui est déjà pricé ?
- qu’est-ce qui reste à repricer ?
- quelle partie du marché est vulnérable ?
- quel catalyst peut déclencher ?
- quelle perte conceptuelle si la thèse est fausse ?
- quel upside conceptuel si elle est juste ?

Le niveau exact de stop/target reste au trader.

---

# QUESTION 17 — QU’EST-CE QUI INVALIDE LA THÈSE ?

Distinguer :

### Weakening
La thèse perd de la force.

### Invalidation
Le mécanisme central n’est plus vrai.

### Flip
Une thèse opposée devient elle-même suffisamment supportée.

Pourquoi ?

Le trader doit savoir quand il ne doit plus défendre son idée.

---

# QUESTION 18 — QU’EST-CE QUI PEUT ME FAIRE CHANGER D’AVIS AU PROCHAIN TRIGGER ?

Donner :

- event ;
- data ;
- market reaction ;
- flow ;
- price response ;
- invalidation ;
- scenario trigger.

C’est la passerelle vers le Global Read suivant.

---

# Les cinq questions asymétrie historiques à conserver explicitement

Même si le framework final contient plus de questions, conserver ce noyau :

1. **Quel flux est réellement observé ?**
2. **Quel participant est réellement contraint / forcé, et pourquoi ?**
3. **Quel funding / carry / coût influence la mécanique ?**
4. **Quel fuse peut déclencher continuation ou unwind ?**
5. **Le prix confirme-t-il réellement le catalyst / la thèse ?**

Ces cinq questions forment le cœur de l’analyse d’exploitabilité.
